# TVからM3U / IPTVで視聴する

TV用APK・配信本体0.5.0以降で、TV内のHTTPサーバー（40560番）からUTF-8のM3UとMPEG-TSを提供します。PCで中継する必要はありません。家庭内LAN向けです。

## 登録方法

1. TV側で0.5.0をセットアップ・再起動し、通信維持を有効にします。
2. TVの「IPTVのM3U接続先を表示」を開き、利用するネットワークとチューナーのURLを確認します。PC直結の169.254.95.200と、ルーターから取得したIPにも対応します。
3. URLをVLCなどのM3U対応アプリへ登録します。アプリにはMPEG-2映像・AAC音声・HTTP MPEG-TSを再生できる機能が必要です。
4. スマホ版0.4.0では、確認コードでTVから接続情報を取り直すと「設定」→「IPTVのM3U接続先」からURLをコピーできます。

例（キーは実際のTV画面またはスマホから取得してください）：

```text
チューナー1: http://TVのIP:40560/iptv/IPTV専用キー/playlist.m3u?tuner=0
チューナー2: http://TVのIP:40560/iptv/IPTV専用キー/playlist.m3u?tuner=1
```

局一覧はTVのスキャン結果から生成します。局を開くと対応するチューナーを選局します。常に放送されていない臨時サービスは受信できない場合があります。

## 同時利用

独立した2チューナーを使えます。各チューナーのIPTVは1セッションずつです。使用中の同じIPTVチューナーへ別セッションを開くと409を返します。BonDriverやスマホ版もチューナーを共有するため、別のチューナーを選んでください。

指定した局のPAT・PMT・映像・音声などのPIDを送ります。別番組やワンセグのPMTを除外するため、汎用プレイヤーが別サービスを選ぶ問題を避けられます。画質変換は行いません。0.6.0からXMLTV形式の番組表を配信します。[XMLTVの登録・収集手順](XMLTV.md)を参照してください。スマホ版の既存の番組表取得は引き続き利用できます。

## 接続情報

M3U URLにはIPTV専用の接続キーが入ります。従来のBonDriver認証キーはURLへ含めません。URLや取得したM3Uを公開しないでください。画像・放送局ロゴ・放送映像の録画は配布物へ同梱しません。

IPが変わった場合は新しいIPのURLへ登録し直します。スマホではIPを保存してからコピーできます。TV側のIP表示は自動更新されます。
