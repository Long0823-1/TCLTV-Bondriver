# スマートフォン接続（TV 0.5.0 / スマホ 0.4.0）

スマホアプリは別リポジトリの[TCLTV-Android-Viewer](https://github.com/Long0823-1/TCLTV-Android-Viewer)で配布しています。

TV APKを0.5.0へ上書きし、「1. セットアップ」を実行して一度TVを再起動してください。今回はネイティブ配信も更新するため、APK上書きだけでは更新は完了しません。[消灯・IPTVの更新手順](SLEEP_IPTV.md)を参照してください。既存のBonDriver接続キーは維持します。

TVで「スマートフォンを接続（確認コードを表示）」を開き、スマホの設定からTV検索またはIP手入力、6桁コード入力で接続情報を取得します。0.4.0では局一覧と従来の接続情報に加え、IPTV専用キーと通信維持の取得時設定も取得します。スマホにroot、PC、USB、ADBは不要です。TVには事前のrootと配信セットアップが必要です。

受付は明示的に開始した2分間・1回のみです。誤コードは5回で停止し、TVで別アプリを開くか受付終了を押しても停止します。受付中だけTCP40559を開き、NSD/mDNSの `_tcltv._tcp.` で検索に応答します。確認コードと接続キーをmDNSへ公開しません。

同じLANのWi-Fi・有線に対応します。検索が使えない場合はIPを入力してください。局一覧はTVのスキャン結果を使用します。スマホの「IPTVのM3U接続先」でURLをコピーできます。URLにはIPTV専用キーを含むため共有先に注意してください。同じチューナーをBonDriver・スマホ・IPTVで同時選局しないでください。

実機TVから37サービスと新しいIPTV設定の取得、誤コード拒否、使用済みコードの拒否を検証しています。
