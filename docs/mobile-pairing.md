# スマートフォン接続（TVセットアップAPK 0.4.2）

スマホアプリは別リポジトリの[TCLTV-Android-Viewer](https://github.com/Long0823-1/TCLTV-Android-Viewer)で開発・配布しています。

既に0.4.1のTS配信が動いているTVでは、TVセットアップAPKを0.4.2へ上書きインストールし「スマートフォンを接続（確認コードを表示）」を選びます。「セットアップ」の再実行や再起動は不要です。接続キーは既存のものを読み取り、変更しません。TS配信のネイティブプログラムとPID設定にも変更はありません。

スマホ側の0.2.0で、TV検索またはIP手入力、6桁コードの入力を行うと、接続キーとTVのスキャン結果に基づく局一覧を取得できます。スマホ側にroot、PC、USB、ADBは不要です。TVのroot権限と配信セットアップは事前に必要です。

接続受付はTV画面で明示的に開始した2分間・1回のみです。誤コードは5回で停止します。TVで別のアプリを開くか、受付終了を押すと停止します。受付中だけTCP40559を開き、NSD/mDNSの `_tcltv._tcp.` で検索に応答します。確認コードと接続キーはmDNSに含めません。通常の視聴では受付機能を動かす必要はありません。

有線LAN・Wi-Fiの同一LAN向けです。マルチキャスト制限のある環境では手動IP入力を使用します。外出先接続機能ではありません。Android TVの局一覧はシステムのTV Providerから読み取り、データ専用サービスなどはWindowsセットアップツールと同様に除外します。

検証: 実TVで37サービスを取得。誤コード拒否・使用後のコード再利用拒否を確認。MediaCodec優先などスマホ側の検証はモバイルリポジトリに記録しています。
