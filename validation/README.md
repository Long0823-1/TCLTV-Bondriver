# 実機検証（2026-10-24）

対象は対応ファームウェアのTCL G06日本向け実機です。

| 項目 | 確認結果 |
| --- | --- |
| 独立した2周波数の同時受信 | ETV 551143kHz / NTV 545143kHz、異なるTSIDを確認 |
| 2分間同時受信 | 2系統目218,111,960バイト、主映像・主音声のスクランブル0、同期・CC・TEIエラー0 |
| ECMバッファ再利用・3分間同時受信 | 2系統目327,535,668バイト、主映像・主音声スクランブル0、同期・CC・TEIエラー0 |
| YouTubeの動画再生中の2局同時PC配信 | 30秒間、両系統の主映像・主音声スクランブル0、同期・CC・TEIエラー0。TV画面の前後で動画の進行を確認 |
| 常駐サービス経由の選局 | TUNE 0 / TUNE 1 とも av_clear=1、2系統目の初回選局約2秒 |
| 実際のBonDriver DLLによる同時受信 | x64の1系統目とx86の2系統目を同時起動し、各約25MBを受信。同期・CC・TEI・PAT CRCエラー0、主映像・主音声スクランブル0 |

| 1系統目のTVTestスキャン中の2系統目 | 約108MBを別ポートで受信し、主AVスクランブル・同期・CC・TEIエラー0 |

| APK | v0.2.0の署名v2/v3検証、上書き導入、Magisk許可後のセットアップに成功 |
| PSI解析 | CRC、連続性、分割、境界、CA PIDなど24項目を検証 |

TVTestのSカウンターは、復号対象外のデータPID等でも増えます。表中のスクランブル0は主映像・主音声の検証です。全PID・全サービスの復号を保証するものではありません。放送TSや映像のキャプチャー、認証キー、ベンダーライブラリー、逆解析出力は配布物に含めません。
