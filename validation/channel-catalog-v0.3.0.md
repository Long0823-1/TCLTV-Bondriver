# v0.3.0 TVスキャン結果のチャンネル一覧

2026-10-24、検証機TCL G06。地デジの地域プリセットを廃止し、TV Providerのスキャン済み登録から取得。

- C#カタログ検証13項目：異なる地域を想定した架空局名、ONIDとTSIDが異なるID、Unicode、カンマ・等号を含む名前、数値順、重複除外、衛星・データ・非表示の除外、0件・不正ID・過長名・512件超の拒否、INI往復を確認。
- 実機DBから地デジAVサービス37件を取得。主・副・臨時サービスを含む。臨時サービスは放送状況によって映像がない場合がある。
- x64/x86 DLLで各4ケース：実機37件の日本語名、架空の他地域2件の日本語名、一覧未設定、上限外設定。全件成功。DLLロード直後のEnumChannelNameで確認。
- 実DLLの同時受信：x64/1系統目、旧固定表になかったNHK総合2（ServiceID 1025）、9,866,240 bytes。x86/2系統目、Eテレ2（ServiceID 1033）、10,155,008 bytes。ともにbad_sync=0、timeouts=0。
- Windows GUIで2系統分のUTF-16 INIとDLLを配置。37件の日本語局名を保持し、配置したDLLからの列挙も成功。
- 一覧変更時に旧BonDriverの.ch2を退避し、バックアップのハッシュ一致を確認。
- Android起動スクリプトの構文と、保存局がない場合にTVの登録局から選局タプルを作る処理を実機の--channel-onlyモードで確認。APK v0.3.0は署名検証・更新インストール成功。

他地域の実機受信、TV本体の再スキャン操作、保存局を消しての実再起動試験は未実施。TV側で再スキャン後にツールで局一覧を再取得し、TVTestでも再スキャンする。ハードウェア・ファームウェアの対応範囲は従来どおり。
